# العهدة — الموبايل

صفحة الموبايل لبرنامج العهدة (اللاب). بتشوف العهدة وبتسجل استلام ومصروف ورد، وبتبعتهم لسكربت جوجل لحد ما البرنامج على اللاب يدخّلهم.

- **الواجهة:** `index.html` (ملف واحد، مفيش مكتبات من النت) + `sw.js` عشان يفتح من غير نت.
- **السكربت:** `apps-script/Code.gs` — مشروع جوجل سكربت جديد ولوحده، البيانات في فولدر «برنامج العهدة (بيانات)» في درايف.
- **الكود المصدري:** في فولدر البرنامج على اللاب (`source/mobile`). الحسابات نفس `core.js` و `calc.js` بتوع اللاب.

## التشغيل أول مرة
1. مشروع جديد في script.google.com ← الصق `Code.gs` ← شغّل `setup`.
2. Deploy ← New deployment ← Web app ← Execute as: **Me** ← Who has access: **Anyone**.
3. شغّل `linkCode` وانسخ «كود الربط» من السجل ← حطه في البرنامج على اللاب (الإعدادات ← 📱 الربط مع الموبايل).
4. من نفس المكان على اللاب: «انسخ لينك الموبايل» وافتحه على التليفون.

بعد أي تعديل في `Code.gs`: Deploy ← Manage deployments ← ✎ ← Version: **New version** (عشان الرابط يفضل زي ما هو).
