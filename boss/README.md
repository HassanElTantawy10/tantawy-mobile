# لوحة المدير — الموبايل

صفحة واحدة بتجمع أرقام كل البرامج: الخزنة والمستحق للمقاولين والموردين والمشاريع (من الحسابات)، والأقساط المستحقة والمتأخرة والتحصيل والعقود (من الأقساط)، والوحدات والمتابعات (من المبيعات).

- **قراية بس:** بتكلم سكربت جوجل بتاع كل برنامج بكود الربط بتاعه، ومش بتبعت أي تعديل.
- **أرقام الحسابات** بتتحسب بكود برنامج الحسابات نفسه (`../index.html`) جوه إطار مقفول من غير تخزين ولا نت — عشان الرقم يبقى نفس اللي في البرنامج بالظبط.
- أكواد الربط وكلمات السر بتتحفظ على التليفون ده بس، متشفّرة برقم سري اللوحة.

بعد أي تعديل في `index.html` غيّر اسم `CACHE` في `sw.js`.
