# ميزانية Hassan

برنامج شخصي للميزانية والمرتب والدخل — بيشتغل على الموبايل والكمبيوتر، ومن غير نت، وبيتزامن مع سكربت جوجل خاص بيه.

- **الواجهة:** `index.html` (ملف واحد، مفيش مكتبات من النت) + `sw.js` عشان يفتح من غير نت.
- **السكربت:** `apps-script/Code.gs` — مشروع جوجل سكربت جديد ولوحده، البيانات في فولدر «ميزانية Hassan (بيانات)» في درايف.
- **الكود المصدري:** `src/` — أي تعديل يتعمل هناك وبعدين `python3 src/build.py`.

## التشغيل أول مرة
1. مشروع جديد في script.google.com ← الصق `Code.gs` ← شغّل `setup`.
2. Deploy ← New deployment ← Web app ← Execute as: **Me** ← Who has access: **Anyone**.
3. شغّل `linkCode` وانسخ «كود الربط» من السجل ← حطه في البرنامج (الإعدادات ← الربط).
4. (اختياري) بوت تليجرام: من @BotFather اعمل بوت وحط التوكن في الإعدادات.

بعد أي تعديل في `Code.gs`: Deploy ← Manage deployments ← ✎ ← Version: **New version** (عشان الرابط يفضل زي ما هو).
